🚀 COMO USAR:
=============

OPÇÃO 1 - Instalação Automática (Recomendada):
1. Execute "install-complete.bat" como Administrador
2. O script verificará automaticamente:
   - Windows 10+ (64-bit)

1. Execute o arquivo .msi diretamente
2. Siga o assistente de instalação
3. Verifique os requisitos manualmente
