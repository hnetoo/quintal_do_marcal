# Rest-IA - Instalador Automático que Funciona 100%

## 🚀 PROBLEMA: MSI não funciona, mas o executável sim!

Depois de horas de trabalho, o instalador MSI tem problemas, mas o executável `rest-ia.exe` funciona perfeitamente.

## ✅ SOLUÇÃO: Script de instalação automática

Este script instala o Rest-IA de forma automática e garantida:

### 📋 Como Usar:

1. **Copie os arquivos** para uma pasta:
   - `rest-ia.exe` (executável principal)
   - `resources/` (pasta de recursos)
   - `sqlite:tasca_vereda.db` (banco de dados, se existir)

2. **Execute o script:**
   ```bash
   INSTALAR.bat
   ```

3. **Pronto!** O script faz tudo automaticamente.

## 🔧 O que o script faz:

1. ✅ **Verifica** se já está instalado
2. ✅ **Cria** pasta `C:\Rest-IA\`
3. ✅ **Copia** todos os arquivos necessários
4. ✅ **Cria** atalho no Desktop
5. ✅ **Abre** o aplicativo automaticamente

## 📦 Estrutura Final:

```
C:\Rest-IA\
├── rest-ia.exe          (Aplicação principal)
├── resources\           (Recursos da aplicação)
└── sqlite:tasca_vereda.db (Banco de dados)
```

## 🎯 Vantagens:

- ✅ **100% funcional** - usa o executável que funciona
- ✅ **Sem problemas** de registro do Windows
- ✅ **Instalação automática** - um clique só
- ✅ **Atalho no Desktop** - fácil acesso
- ✅ **Abre automaticamente** após instalação
